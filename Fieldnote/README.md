# Fieldnote · 현장 소리 도감

숲·물가·도시의 풍경을 소리로 표현한 네 개의 기록을 들어 보고, 검토를 마친 기록에 표시하는 작은 웹 앱입니다. 각 기록의 6초짜리 모노 음원과 파형은 브라우저에서 같은 샘플로 생성합니다. 장소와 녹음 시각은 시연용 예시입니다.

## 실행

Finder에서 이 폴더의 `index.html`을 이중 클릭하면 기본 브라우저에서 바로 열립니다. 패키지 설치, 인터넷 연결, Local Desk 실행은 필요 없습니다.

시연 때마다 같은 주소에서 검토 표시를 이어 보려면 Python 3으로 실행하세요.

1. 터미널에 다음 두 줄을 입력합니다.

   ```bash
   cd "/Users/oscar/Desktop/SecureCode/Fieldnote"
   python3 -m http.server 8765 --bind 127.0.0.1
   ```

2. 터미널을 열어 둔 채 브라우저에서 [현장 소리 도감](http://127.0.0.1:8765/)을 엽니다.
3. 시연이 끝나면 터미널에서 `Control+C`를 눌러 서버를 종료합니다.

## 첫 기록 검토하기

1. **기록 목록 → 물가**를 누릅니다. **방파제의 잔물결**과 **연못에 닿는 빗방울** 두 건이 남습니다.
2. **방파제의 잔물결**을 선택하고 **샘플 재생**을 누릅니다. 약 4초 지점의 큰 너울에 맞춰 재생 표시가 파형을 지나갑니다. 재생 중에는 **재생 정지**로 처음 위치로 돌아갈 수 있습니다.
3. **관찰 메모**에서 **레벨 주의 · -6 dBFS**를 확인한 뒤 **이 기록 검토 완료**를 선택합니다. 상단의 검토 완료 수가 하나 늘고 목록에 체크 표시가 생깁니다.
4. 같은 브라우저와 주소에서 새로 고치고 해당 기록을 다시 선택합니다. 브라우저가 로컬 저장을 허용하면 검토 표시가 유지됩니다. 체크를 해제하면 다음 시연에서 다시 검토할 수 있습니다.

## 터미널에서 레벨 보고서 보기

프로젝트 폴더에서 다음 명령을 실행합니다. Python 표준 라이브러리만 사용합니다.

```bash
python3 capture_report.py
```

기본 설정에서는 기록 4개에 대해 각각 48개 구간의 가상 레벨을 출력하고, 마지막 줄에 `CAPTURE_SUMMARY`와 총 구간 수, 가장 큰 레벨, 장비 이름을 표시합니다. 난수의 시작값을 고정했으므로 같은 설정으로 다시 실행하면 같은 보고서를 얻습니다. 앱에서 표시하는 피크는 각 합성 음원의 레벨이고, 보고서는 별도의 장비 점검용 모의 측정입니다. 브라우저 샘플의 재생 주파수는 22.05 kHz이며, 장비 설정 파일의 48 kHz는 현장 캡처 프로필 값입니다.
