이 폴더는 2026-10-24 시작한 RF/RH/C 큰 파일 실험 기록이다.
입력은 large_files_20261024의 원문·문제·원문 후보를 그대로 복사했다.
protocol.json에 입력과 실행 코드의 SHA-256, 설정, 실행 순서를 생성 전에 고정했다.

실행 순서:
1. experiment_raptor_large.py prepare (새 출력 폴더 필요)
2. 기존과 같은 llama-server: 포트 8766, ctx-size 8192, parallel 1,
   no-warmup, cache-ram 0, no-cache-prompt; environment.json에 정확한 모델/서버 경로와 해시.
3. experiment_raptor_large.py build
4. build_raptor_example.py (독립 예제 폴더, 평가에서 제외)
5. experiment_raptor_large.py dev
6. experiment_raptor_large.py run
7. analyze_raptor_large.py
8. verify_raptor_large.py
9. 검증을 확인한 뒤 report_raptor_large.py

실제 실행은 continue_raptor_large.py가 3번 완료를 기다린 뒤 4~8번을 순서대로 호출했다.
별도의 모델 답변 공유나 이전 결과를 새 답변으로 대체한 행위는 없다.
비교에 재사용한 A/B/R0/FULL 결과는 이전 세션의 실제 결과임을 명시한다.
독립 검증은 토크나이저를 오프라인 실행하며 새 답변을 생성하지 않는다.
source_snapshot에 실행 시점의 소스를 보존했다.

최종 확인: audit_raptor_report.py로 수치·예제·문서 링크·기존 기록 보존을 재점검한다.
이미 완료된 기록에서는 7~9번과 최종 확인을 다시 실행할 수 있으며 새 모델 답변은 만들지 않는다.
새 답변을 다시 생성하려면 기존 증거 폴더를 덮어쓰지 말고, 스크립트를 복제하여 OUT을 별도 경로로 지정한 뒤 새 계획을 고정해야 한다.
최종 보고서 생성기와 점검 코드는 source_snapshot의 *_final.py 및 audit_raptor_report.py에 별도로 보존했다.
