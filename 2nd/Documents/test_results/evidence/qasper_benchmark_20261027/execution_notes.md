## 이번 실행

- 원본: SCROLLS 고정 리비전의 QASPER validation. 이전에 무결성 확인을 마친 동일 원본을 복사했고 새 폴더에서 크기·SHA256을 다시 확인했다.
- 자료 준비는 새로 수행했다. 원문 분할·목록·연결 생성 및 저장 50.0728초. 984개 질문·1,726개 참조 행·273개 원문과 모든 구간·연결이 독립 전수 검증을 통과했다.
- 3개의 토크나이저 대조와 실제 전송 점검 1회가 통과했다. 이 점검 호출은 모든 평가 집계에서 제외한다.
- 실험 전 문항별 FULL 길이를 확인했다. 984개 모두 32,768 한도에 들어가며 입력과 128토큰 출력 예약의 합계 최대는 22,192다.
- Qwen2.5-Coder-7B-Instruct Q5_K_M, 로컬 llama-server, 동시 호출 1개, 컨텍스트 32,768, 프롬프트 캐시 비활성화. 사용자 컴퓨터의 다른 작업에 따른 시간 변동까지 통제한 실험실 속도 측정은 아니다.
- 실행 명령 설정: `--ctx-size 32768 --parallel 1 --no-warmup --cache-ram 0 --no-cache-prompt`.
- 평가 순서와 분석 계획 및 소스·모델·자료 해시를 평가 시작 전에 고정했다. 후처리 소스 5개는 별도 `postprocess_manifest.json`으로 고정했다. 전송 점검만 있고 평가 결과가 없던 최초 동결 시도는 후처리 파일 분리를 위해 폐기했고 `history/preflight_freeze_attempt`에 보존했다.
- 실제 평가 시작은 `environment.json`·`session_*.json`에, 전체 완료는 `completed.json`에 기록한다. `progress.json`은 진행 상황이고 완료 증거가 아니다.
- 각 요청은 전송 전에 저장하며 실제 응답도 보존한다. 미해결 요청은 자동 재시도하지 않는다. 질문별 원자적 결과 파일과 JSONL의 일치 여부를 최종 검증한다.
- 총 평가 결과는 3,936행, 평가 호출은 5,904회이다. 연결 점검을 합친 호출 기록 수는 5,905개가 되어야 한다.

## 완료와 보고서 반영 조건

감독 작업은 실행기 잠금이 풀린 뒤 완료 마커와 결과 수를 확인한다. 이후 분석, 독립 전수 검증, 보고서 반영을 순서대로 실행한다. 하나라도 실패하면 후속 단계를 중단한다. 최종 완료 여부와 각 단계 기록은 `postprocess_status.json`, 원자료 검증은 `verification.json`, 문서 반영은 `report_update_verification.json`으로 확인한다. 이 기록 자체는 완료를 선언하는 문서가 아니다.
