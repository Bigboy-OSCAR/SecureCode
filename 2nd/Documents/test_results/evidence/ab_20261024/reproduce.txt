Dependencies
  System Python and the existing local llama.cpp installation/model.
  No new packages or network model services are required.
  The original experiment, audited client, indexer, selector and source corpus
  are hash-pinned in protocol.json; source_snapshot contains code copies.

Measurement and interpretation
  Main time = mean over 96 question-specific medians of three physical requests.
  Request p95 uses all 288 requests per arm.
  Physical time includes selector, expansion, packing/token counting and answer.
  Model loading, initial index/graph preparation and grading are excluded.
  Token counting durations overlap processing stages and are not added twice.
  Whole source fragments that do not fit the 1024-token cap are skipped.
  Primary accuracy requires exact JSON values/types and requested list ordering.
  Order-tolerant accuracy is a secondary list-order-only diagnostic.
  Confidence intervals resample six project clusters, not repeated requests.
  A/B formatting and import presentation differ as well as traversal scope.
  This is a local replication on known small projects, not a broad deployment claim.

Review
  verify_ab.py independently grades output and recomputes primary and breakdown
  statistics. Context reconstruction reuses the unchanged implementations.
  A separate tokenizer verifies candidate/context/prompt token counts offline.
  Runtime settings, hashes and UTC records provide local provenance, not external
  certification or an externally signed preregistration.
