R0 동일 질문 재실험 재현 안내

원자료 위치
- A/B: /Users/oscar/Desktop/SecureCode/2nd/Documents/test_results/evidence/ab_20261024
- R0: /Users/oscar/Desktop/SecureCode/2nd/Documents/test_results/evidence/r0_20261024
- 스크립트: /Users/oscar/Desktop/SecureCode/2nd/experiments/symbol_raptor

기존 원자료를 덮어쓰지 않으려면 새 출력 경로를 사용한다.
아래 명령은 프로젝트 루트 /Users/oscar/Desktop/SecureCode 에서 실행한다.

1. 아직 존재하지 않는 출력 경로를 준비한다.

R0_REPRO_OUT=/Users/oscar/Desktop/SecureCode/2nd/Documents/test_results/evidence/r0_reproduction_new
python3 2nd/experiments/symbol_raptor/experiment_r0.py prepare --out "$R0_REPRO_OUT"

이 단계는 A/B의 고정된 96문제와 프로젝트 원문을 복사하고 기준 정답을 다시 확인한다.
원래 R0 후보와 같은지 검사하고 입력·코드 해시를 저장한다.
새 경로에 protocol.json이 이미 있으면 중단하므로 다른 새 경로를 정한다.
현재 보고서도 새 실험 폴더의 history/report_before_R0.md에 보관한다.

2. 별도 터미널에서 동일한 모델 서버를 실행한다. 8766 포트는 비어 있어야 한다.

/opt/homebrew/bin/llama-server -m /Users/oscar/Desktop/SecureCode/1st/symbol_test/work/models/qwen2.5-coder-7b-instruct-q5_k_m.gguf --host 127.0.0.1 --port 8766 --ctx-size 8192 --parallel 1 --no-warmup --cache-ram 0 --no-cache-prompt

3. 모델 로딩이 끝나면 개발용 8문제와 본 평가 96문제 × 3회를 순서대로 실행한다.

python3 2nd/experiments/symbol_raptor/experiment_r0.py dev --out "$R0_REPRO_OUT"
python3 2nd/experiments/symbol_raptor/experiment_r0.py run --out "$R0_REPRO_OUT"

각 호출마다 실제 답변을 생성한다. R0에는 AI의 출발 함수 선택 단계가 없다.
개발용 답변 8개와 세션별 예열 답변 2개는 평가 점수에서 제외한다.
이번 원본 실험은 중단·재개 없이 수행하도록 계획했다. 중간 재개 시 추가 예열 로그가 남으므로
검증기의 '정확히 두 번의 예열' 검사도 그 사실을 드러내며, 원본과 같은 무중단 실행으로 가장 쉽게 재현할 수 있다.
서버의 모델·실행 파일·설정이 보존한 A/B 환경과 다르면 실행을 중단한다.
다른 장비/버전으로 확장 평가하려면 별도 계획과 기준 실험을 만들고 결과를 섞지 않는다.

4. 측정 완료 후 집계하고 오프라인으로 검증한다.

python3 2nd/experiments/symbol_raptor/analyze_r0.py --out "$R0_REPRO_OUT"
python3 2nd/experiments/symbol_raptor/verify_r0.py --out "$R0_REPRO_OUT"

검증은 별도 llama-tokenize 실행 파일과 같은 모델 어휘를 사용한다.
서버 측정 중 토큰 검증을 동시에 실행하면 장비 부하에 영향을 줄 수 있으므로 완료 후에 한다.
verification.json의 PASS를 확인한다. A/B 원자료는 수정하지 않는다.
R0와 보존된 A/B는 다른 실행 세션이므로, 시간 차이를 방식만의 순수 효과로 해석하지 않는다.

5. 지정된 보고서를 갱신하려는 경우에만 아래 명령을 실행한다.

python3 2nd/experiments/symbol_raptor/report_r0.py --out "$R0_REPRO_OUT"

이 명령은 검증된 수치로 다음 기존 Markdown 파일을 갱신한다.
/Users/oscar/Desktop/SecureCode/2nd/Documents/test_results/03_현재색인_A와_파일간확장_B_재실험_비교보고서.md

source_snapshot에는 실험·집계·검증·보고서 생성 코드가 보관되어 있다.
protocol.json은 실행 입력과 원래 R0 구현을, analysis_plan.json은 평가 완료 전 준비한 분석 코드를 기록한다.
완료 후 completion_audit.json과 report_manifest.json에서 최종 코드·보고서 해시를 확인할 수 있다.
기존 A/B report_manifest.json은 갱신 전 보고서에 대한 기록이다. 그 보관본은 history/report_before_R0.md이며,
갱신된 보고서에는 R0 폴더의 새 report_manifest.json이 적용된다.
