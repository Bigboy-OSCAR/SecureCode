## 3. 4.1 설계와 로드맵·3.1 실측의 차이 (4.2/4.4 결정 요청)

[POINTER_DESIGN.md](../architecture/POINTER_DESIGN.md)는 3.2를 시작할 수 있을 만큼의 수명주기·URI·포트 목록을 제공했다(선행 충족 판정). 다만 아래 항목은 로드맵 0.4/0.7과 3.1 실측에 어긋난다. 3.2 계약은 **로드맵·실측 쪽을 따랐다.** 4.2/4.4에서 POINTER_DESIGN.md를 고치거나 근거를 남겨 주기 바란다.

| # | POINTER_DESIGN.md | 로드맵·실측 | 3.2가 따른 것 |
| --- | --- | --- | --- |
| D-1 | ToolResultTransformer: "SDK appends the descriptor to canonical history through appendContext" | 0.4: `afterTool`의 **`result`를 교체**해야 하고, appendContext만으로는 Runtime Pointer가 아님. 3.1: result 교체로 원문 0건 입증 | `ToolResultOutput.text`로 result 교체 |
| D-2 | Raw tool-result payload cap 16 KiB | 3.1 C-07: SDK가 8,000자 초과 결과를 provider 요청에서 자르므로 임계값은 8,000자 미만이어야 함 | 임계값 결정은 4.4. 포트는 `outputBytes`를 넘김 |
| D-3 | Runtime quota 32 MiB/session, 128 MiB/workspace | 0.7: Runtime **객체** 최대 32 MiB, **세션 합계** 128 MiB | settings `limits`는 4.2 확정 후 채움 |
| D-4 | Read token cap "32 KiB tokens" | 0.7: 부분 조회는 32 KiB와 요청 token cap 중 작은 값(바이트와 토큰은 다른 단위) | — |
| D-5 | Source quota per workspace 256 MiB | 0.7: Source **파일** 최대 256 MiB | — |
| D-6 | Context Service unavailable → "SDK_UNAVAILABLE or configured fallback" | 0.4: 실패 시 원문 fallback 금지(fail-closed) | 서비스 불가는 `SERVICE_UNAVAILABLE`(host 측). hook은 throw |
| D-7 | Hook timeout: "Follow configured hookErrorMode" | 3.1 S-04: SDK가 hook timeout을 강제하지 않음. hook이 자체 timeout 후 throw해야 함 | 포트 계약에 "timeout 시 throw" 명시 |
| D-8 | 증거 파일 위치 | 4.1 기록이 저장소 루트 `docs/progress/tasks/4.1.md`에 있음(작업 루트 `2nd/Project/docs/progress/tasks/`가 아님). 명령 결과 일부가 실제 출력이 아니라 "Expected result"로 적힘 | 3.2는 존재·내용을 확인하고 선행 충족으로 판정. 위치 이동은 담당자가 결정 |

## 4. 3.2 이전 포인터 코드 (4.3/4.4 재작업용, baseline `KNOWN`)

`scripts/check/structure-baseline.json`의 13개 항목(구조 검사 23건)과 `apps/host/tsconfig.legacy.json`에서 발견한 내용이다. 3.2는 이 파일들을 수정하지 않았다.

- **SDK 타입 불일치(strict Bundler에서 23개 오류):** `ClineCore.use`(없음), `ClineCoreOptions.plugins`(없음), `beforeModel` context의 `messages`/`appendContext`(없음), afterTool이 문자열 `result`를 반환함(`AgentToolResult`여야 함). 기존 tsconfig(`NodeNext`)에서는 SDK 타입이 `any`가 되어 이 오류가 숨겨져 있었다(3.1 C-01).
- `src/cline-plugins/test-*.ts`: 실행기가 production `src/`에 있다. `apps/host/tests/`로 옮겨야 한다.
- Python `api/pointers.py`: 모듈을 import하면 `SQLiteRuntimeStore()`가 현재 폴더에 `runtime_pointers.db`를 만든다. 경로가 `/api/v1/pointers/runtime`이라 내부 경로 규칙(`/internal/v1`)과 계약(ApiError·pagination·PointerDescriptor)을 따르지 않는다. 3.2의 정식 진입점은 `python -m securecode_context.app`이고, 이 router는 아직 등록하지 않았다(등록은 `app/factory.py`).
- docstring 규약 미적용(10개 파일), `Optional[...]` 표기(ruff UP045, 해당 경로만 예외).
- 조치 후 baseline 항목, `.prettierignore`·`eslint.config.js`의 legacy 경로, `pyproject.toml`의 per-file-ignores·mypy override를 지우면 된다. 그러면 `check`가 자동으로 엄격해진다.
