# 1.1 UI workspace·lockfile 인계

> 발신: 김민지 1.1 · 수신: 박준형 (루트 workspace·lockfile 소유자) · 작성일: 2026-11-06 (Asia/Seoul)

## 변경

- 루트 `package.json`의 workspace 목록에 `apps/ui`를 추가했다.
- 단일 lockfile 소유 규칙에 따라 루트 `package-lock.json`을 갱신했다. UI 패키지는 React/React DOM `19.3.1`, Vite `8.3.6`, React Vite plugin `6.2.1`과 타입 패키지를 정확한 버전으로 고정한다. 별도 UI lockfile은 만들지 않았다.
- 루트 `scripts/lib/steps.ts`의 타입 검사 프로젝트 목록에 `apps/ui`를 추가했다. 기존 루트 검사가 새 workspace 타입을 계속 검사한다.
- 루트 `eslint.config.js`에서 TSX도 TypeScript 검사 대상으로 지정하고, PascalCase React 컴포넌트 함수 이름을 허용했다.
- Vite 개발 서버는 `127.0.0.1:5173`에서 실행하며 `/api/v1`만 host `127.0.0.1:8787`로 proxy한다. UI client에는 SDK·내부 service·비밀값 환경변수를 연결하지 않았다.

## 검증

- `npm ci`: 성공. 전체 workspace 의존성 설치에서 35개 보안 권고(낮음 4, 중간 21, 높음 8, 심각 2)가 보고됐다. 이번 UI의 production dependency 범위 `npm audit --workspace=apps/ui --omit=dev`는 취약점 0개다.
- `npm run typecheck --workspace=apps/ui`, `npm test --workspace=apps/ui`, `npm run build --workspace=apps/ui`: 통과. render test 2개, production Vite build 23개 모듈.
- `npm run check:structure`: PASS, 신규 위반 없음.

루트 실행 도구와 lockfile은 박준형 소유 범위이므로 위 변경을 인계한다. 루트 전체 audit 권고의 분류·조치는 UI 작업에서 변경하지 않았다.
