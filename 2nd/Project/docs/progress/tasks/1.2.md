## 5. 제한

- 이번 작업은 fixture 기반 UI이며 실제 Host API/SSE/SDK 연동은 하지 않았다. 사용자 조작은 확인 가능한 로컬 예시 상태만 바꾸며 서버 성공으로 표시하지 않는다. 실제 API 교체와 상태 전이는 1.3/1.4 범위다.
- 최초 기록 시에는 `uv` 미설치로 Python 계약 검증이 실행되지 않았으나, 2026-11-09 재실행에서 TypeScript 232개와 Python 200개 계약 시험이 모두 통과했다. Python 시험은 Starlette의 `httpx` 사용 중단 경고를 출력했다.
- 전체 구조 검사는 기존 context-service routes의 레이아웃 위반 4개로 실패했다. 해당 파일은 이번 변경 대상이 아니며 수정하지 않았다.
