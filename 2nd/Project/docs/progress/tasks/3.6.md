## 제한

- live는 로컬 Qwen2.5-7B-Instruct 한 모델, Windows 한 대에서만 했다. 모델 답은 비결정적이다. PDF 단계에서 모델이 지어낸 cursor를 먼저 넣는 일이 반복됐다(서버가 거절하고 재시도해 통과). Anthropic provider live는 키가 없어 하지 않았다.
- live에서는 provider 요청 본문을 캡처하지 않았다(실제 fetch). 본문 누출은 scripted SDK 시험으로, live는 SDK 대화 기록으로 확인했다.
- 자동 current_task 후보는 host가 보내지 않는다. 포인터 범위를 넣으려면 사용자가 명시 선택해야 한다.
- 세션 context 기록(보인 범위·직전 메시지)은 메모리에만 있다. host를 재시작하면 SDK 세션도 새로 시작한다.
- PDF job ID → 작업 공간 표가 메모리에만 있다. 재시작 뒤 조회는 404이고, 다시 parse하면 된다.
- POSIX(macOS/Linux) 실행은 하지 않았다(3.7).
- 4.10의 저장소 루트 `tests/integration/test_pointer_context_pdf_integration.py`는 예전 API를 import해 깨져 있다. 실행하는 스크립트는 없다.
