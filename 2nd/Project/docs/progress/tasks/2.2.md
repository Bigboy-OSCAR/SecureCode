## 5. limitations

- 이는 설계 문서 검사다. UI 렌더·접근성 실측·자동 행동 시험·실제 API/SDK/provider·PDF Skill·bounded I/O는 실행하지 않았다. 앱 코드가 없는 상태를 UI 시험 성공으로 기록하지 않는다.
- 이번 환경에는 node_modules·서비스 가상환경·Python jsonschema가 없다. 의존성을 새로 설치하거나 `npm run check/test:contracts/build`를 실행하지 않았다. 스키마/fixture의 **참조·내용 대조**를 했으며 Ajv/jsonschema의 전체 payload 검증 통과로 바꿔 기록하지 않는다. 이전 3.2/4.2 시험 결과는 선행 기록일 뿐 이번 실행 결과가 아니다.
- 계약 보완 없이 임의 DTO·PDF status enum·preview 요청·전체 포인터 선택을 추가하지 않았다. 2.2의 완료 체크와 다른 담당 체크는 변경하지 않았다.
- 이 인계는 저장소 문서로 남겼으며 다른 사람에게 외부 메시지를 보내지 않았다. Git commit/push는 실행하지 않았다.
