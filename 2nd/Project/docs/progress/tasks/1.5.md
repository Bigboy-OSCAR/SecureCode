## 인수 근거와 미완료 조건

- 등록된 Python workspace의 실제 색인 상태와 PDF 파싱 완료 상태, PDF 원본 문서/페이지 수 및 parser 출처가 UI에 표시됐다.
- Source 등록 화면은 사용자가 입력한 외부 경로만 전송하며, 목록 preview는 `boundedPreview`로 제한한다. 본문 읽기는 사용자가 범위를 요청하는 별도 동작이고 화면은 요청당 최대 4,096 bytes 및 cursor 후속 조회를 안내한다. UI 계약 테스트에서도 장문 preview 제한을 검사했다. 다만 네트워크 응답 전체의 byte 수를 별도 계측하지는 않았다.
- 실제 R0 검색 및 Source/PDF 본문 읽기에서 계수기 오류가 발생해 context budget preview의 정상 결과·선택/누락 사유·계수 모드·비교 가능한 절감률을 실서비스로 확인하지 못했다. Context preview live 요청과 실제 Runtime pointer가 포함된 run 검증도 완료하지 못했다.
- 따라서 로드맵 1.5 완료 조건 중 “R0·Source·Runtime·PDF·예산 화면 모두 실서비스 동작”은 충족하지 않았다. `INTEGRATED_SYSTEM_IMPLEMENTATION_ROADMAP.md`의 1.5 체크는 `[ ]`로 유지한다. 재개 시 실제 counter를 host/service 설정에 등록하고 healthy 상태를 확인한 다음 Context preview와 Source/PDF read/search를 재검증하고, Runtime 결과가 생기는 실제 run으로 출처·만료·run 격리를 확인해야 한다.
