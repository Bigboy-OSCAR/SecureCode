## 5. limitations

- live provider·live `count_tokens`·네트워크 재시도는 검증하지 않았다(키 불필요 작업, 4.8/3.6 범위).
- Node 26.13.0에서만 실행했다. Node 22/24 재실행은 3.2에서 한다.
- ESLint/Prettier는 아직 구성되지 않았다(3.2 소유). 이번 정적 검사는 strict `tsc`와 문서/구조 검사 스크립트다.
- checkpoint 대조 실험(켜기)은 금지 규칙 때문에 하지 않았다. spy와 Git fingerprint로 꺼짐만 확인했다. fixture 저장소에는 commit이 없다.
- file-form plugin의 guarded hook 경로, MCP 연결, hub/remote backend는 비활성화 대상이라 검증하지 않았다.
- 승인 broker와 pointer hook은 검증기용 최소 구현이다. 3.5/4.4가 정식으로 구현한다.
