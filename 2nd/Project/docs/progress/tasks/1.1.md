## 5. limitations

- 현재 화면은 다음 화면 작업이 import할 기반 레이아웃과 공용 표현 요소다. 프로젝트 등록/선택 동작, 대화 상태, 사용자 행동, 실제 SDK/API 연결은 구현하지 않았다.
- 전체 workspace의 `npm ci`는 35개 취약점 advisory를 보고했다. UI production dependency 범위 audit은 0개이며, 루트/타 workspace 의존성의 advisory는 그 소유 작업에서 검토해야 한다.
- 브라우저 검증은 이 실행 환경의 Vite 개발 서버에서 수행했다. Windows 검증과 host API/SDK live 연결 검증은 이 작업 범위가 아니다.
