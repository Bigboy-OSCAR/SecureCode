## 완료한 인수 작업

- 기존 완료 체크를 그대로 신뢰하지 않고 고정 의존성부터 복구하고 다시 실행했다.
- Node/Cline SDK·Python 서비스·React UI를 실제 프로세스로 검증했다. 모델 응답을 정한 자동 시험과 실제 로컬 모델 호출을 분리했다.
- 새 임시 폴더 설치/기동/종료/재시작 9개 검사 통과, 사용자 원본/데이터 보존 확인.
- Mac 앱은 Swift/WKWebView, 빌드 UI, 자동 인증, 서비스 종료, native 폴더 선택, 인증 갱신, 선택 ID 보존을 연결했다. 앱 데이터를 macOS Application Support로 이전하며 원본과 모델 가중치를 보존하고 SDK 저장 경로만 수정했다.
- Figma sidebar/chat/모델/프로젝트/색인/이전대화/search 구성으로 UI를 재구성했다.
- 실제 Qwen2.5 smoke 12개와 MLX↔GGUF 교체, 정확 tokenizer 대조, 실제 요청 7회의 최대/누적 입력 측정을 기록했다.
- CUA에서 native 폴더 선택, 5언어 1,009파일 색인, 실제 질문/답, 승인 로그 부분 조회, Source 및 PDF 페이지 읽기 등을 수행했다. 최신 수정도 재실행하여 확인했고 열린 차단 결함은 없다.

## 검사·측정·실행 증거

최신 결과는 [최종 인수 보고서](../../release/ACCEPTANCE_REPORT.md)의 검사/F1–F11/AC-01–34 표에 연결했다. 실제 모델 입력량은 [측정 JSON](../../../artifacts/verification/localdesk-mac/context-measurement.json), native 동작은 [CUA 기록](../CUA_MAC_ACCEPTANCE_2026-11-11.md), 실행 방법은 [RUNBOOK](../../release/RUNBOOK.md)을 따른다.
