## 이전 판정과 이번 재작업

2026-11-09 재검토는 4.3을 **INCOMPLETE**로 판정했다. 남은 조건은 다음과 같았다.

- 다중 저장소 동시 quota
- 저장 실패 후 orphan 복구
- checksum 검증
- token cap
- scope에 묶인 cursor와 전체 selector 계약

기존 기록에는 실제 실행 결과가 없었다. 이번 재작업에서 저장소를 v2 스키마로 다시 구성했다. 4.6에서 만든 텍스트 읽기 엔진은 `pointers/text/`로 옮겨 Source와 Runtime이 함께 쓴다.

## 제한

- **호환 경로**: host는 아직 `/runtime/pointers/read`(숫자 offset, 토큰 상한 없음)로 읽는다. host `runtime_search` 도구는 앞 16 KiB만 클라이언트에서 검색한다. 둘 다 4.4에서 `/runtime/read`·`/runtime/search`로 바꾸고 호환 경로를 지운다.
- **토큰 계수기 필요**: 계약형 읽기·검색은 TokenCounter가 있어야 한다. 운영 기본값(계수기 없음, 로컬 qwen 미지원)에서는 `TOKENIZER_UNAVAILABLE`이다. 시험은 `FixedTokenCounter`로 했다.
- `synchronous=NORMAL`이라 정전 시 가장 최근 행이 사라질 수 있다. blob은 fsync 후 행을 기록하며, 재시작 복구가 행 없는 blob을 지운다.
- 10,001개 시험은 Windows에서 약 55초 걸린다(객체마다 fsync).
- **레거시 API**: 별도 레거시 앱(`api/main.py`, `api/pointers.py`, `pointers/runtime/sqlite_store.py`)은 건드리지 않았다. 운영 경로가 아니며, 4.4에서 host의 `api: "legacy"` 분기와 함께 정리 여부를 정한다.
- 저장 자료는 UTF-8 텍스트만 받는다(도구 출력). 이진 출력은 `VALIDATION_FAILED(invalid_utf8)`이다.

## 다음 인계 (4.4)

- **스트리밍 포트**: `RuntimeStore.open_writer(RuntimePut(ws, ses, media_type, b"", origin=tool, truncated_before_storage=...))` → `writer.write(chunk)`* → `writer.commit()`은 descriptor, 취소·실패는 `writer.abort()`. HTTP로는 `POST /internal/v1/runtime/pointers`에 `origin`을 반드시 넣는다. 제한된 읽기 도구 이름이면 `VALIDATION_FAILED(bounded_read)`다.
- 실제 오류 예시(`details.reason`):
  - `QUOTA_EXCEEDED(object_limit|session_limit|disk_full)`
  - `SERVICE_UNAVAILABLE(disk_error)`
  - `NOT_FOUND(deleted|session_cleared|lost|unknown)`
  - `EXPIRED(expired)`
  - `FORBIDDEN`(다른 세션 URI)
  - `INVALID_POINTER`(cursor 변조·다른 요청)
  - `INTERNAL_ERROR(checksum_mismatch|blob_missing|blob_size_mismatch)`
- 도구는 `/runtime/read`(selector·cursor)와 `/runtime/search`(cursor로 이어 검색)로 바꾸고 응답 `next_cursor`를 그대로 넘긴다. 세션 종료 때 `/runtime/sessions/clear`, 주기 정리는 `sweep_expired`(별도 스케줄)다.

## 2026-11-10 4.4 이후 변경

4.4에서 host를 계약 경로(`/runtime/read`·`/runtime/search`)와 스트리밍 저장(`/runtime/stream`, 신규)으로 바꿨다. 그래서 호환 offset 경로 `/runtime/pointers/read`와 `RuntimeReader.read_bytes`를 제거했다. 위 "호환 경로" 제한은 해소됐다. [4.4 기록](4.4.md)
