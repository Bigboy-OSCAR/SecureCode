API·조립:

- `api/sources.py`: `/internal/v1/source/register|refresh|stat|list|unregister`. pydantic 본문 검증(extra 금지, unregister의 `session_id` 거부)을 한다. 실행은 threadpool에서 한다.
- `api/source_wire.py`: 계약 JSON 변환. 서버 절대 경로는 응답에 넣지 않는다. 외부 등록은 `relative_path`를 생략한다.
- `app/factory.py`: `create_app(..., workspace_roots=None)`과 `build_source_registry`를 추가했다. 데이터 폴더에 등록부와 파생 캐시를 두며, 데이터 폴더는 외부 등록 금지 경로다. lifespan에서 연결을 닫는다.
- `docs/contracts/API.md` 4절에 내부 경로와 idempotency 책임을 기록했다.

정책 결정:

- **revision**: 등록부는 정수 revision을 쓰고 URI는 `?v=<revision>`이다. 원본이 바뀌어도 stat이 자동으로 revision을 올리지 않는다. 사용자가 `refresh`(또는 같은 경로 재등록)할 때만 올리고, 이전 URI는 `SOURCE_CHANGED`(`details.current_revision`)를 받는다.
- **재해시 정책**: identity가 같으면 재해시하지 않는다. identity는 장치, inode/파일 index, 크기, mtime_ns, ctime(Windows는 ChangeTime)이다. 다를 때만 전체 hash를 다시 계산한다. 수정 시각만 바뀌고 내용이 같으면 revision을 유지한다.
- **경로는 저장하지 않고 매번 해석**: workspace 원본은 root 포트로 root를 얻고, 외부 원본은 저장된 grant root를 다시 확인한다(링크로 교체되면 FORBIDDEN). 재시작 뒤에도 같은 검사를 한다.
- **등록 해제**: 등록 행, 파생 캐시 참조, 더 이상 쓰지 않는 외부 grant를 지운다. 원본 파일은 건드리지 않는다. 없는 등록의 해제도 같은 효과로 응답한다.

## 제한

- **POSIX 경로 미실행**: macOS/Linux의 `O_NOFOLLOW` dir-fd 열기 경로와 파일 symlink 시험은 이 환경(Windows, symlink 권한 없음)에서 실행되지 않았다. Windows의 junction·`final_path` 경로만 실행했다. 3.7 회귀에서 macOS/Linux 실행이 필요하다.
- **아직 연결되지 않은 것(3.6 범위)**:
  - 서비스 기본 root 포트는 `UnconnectedWorkspaceRoots`(fail-closed)다. host 작업 공간 등록부 연결은 3.6이 한다.
  - `SymbolIndexService`에 `registry.lookup`을 주입하는 것은 3.6 조립 범위다. 현재 기본값은 미등록 fixture다.
  - host 공개 route는 아직 501이다.
- `idempotency_key`는 형식만 검사한다. 키 재전송의 결과 재생과 충돌(`IDEMPOTENCY_CONFLICT`)은 host route(3.6)가 맡는다. 등록·해제는 같은 원본에 대해 멱등이다.
- 등록 시 전체 hash는 1회 계산한다(최대 256 MiB). 이후 stat/read는 identity가 같으면 재해시하지 않는다.
- 메모리 등록부 `store.py`(`SourceStore`)는 시험에서만 쓰는 레거시로 남겼다. 4.6에서 reader에 흡수하거나 제거한다.
- `readers.py`/`search.py`의 전체 scan(P10), token cap·cursor(P11), PDF 파서(P1~P4)는 4.6/4.9에서 고친다. 이번 4.5 완료는 bounded read 완료를 뜻하지 않는다.

## 다음 인계

- **4.6**: `SourceRegistry.resolve(workspace_id, pointer)` → `ResolvedSource(record, root, real_path)`를 받아 `open_verified(root, record.relative_path)`로 연다. `identity_of(file) == record.identity`를 읽기 전후로 확인한다. 줄 오프셋 index는 `record.fingerprint`/`identity`에 묶어 캐시한다. `supported_selectors`는 `media.supported_selectors`와 맞춘다.
- **4.9**: PDF 파생 캐시는 `DerivedCacheDirectory.path_for(cache_key)`에 쓰고 `registry.attach_derived(workspace_id, pointer, cache_key)`로 참조를 등록한다. revision이 바뀌거나 등록이 해제되면 마지막 참조에서 삭제된다. 형식 판정은 등록 시 `%PDF-` 서명 일치까지만 한다.
- **3.6**: `create_app(..., workspace_roots=<host 작업 공간 포트>)`, `SymbolIndexService(source_registry=registry)`를 연결한다. host 공개 `POST /workspaces/:id/sources`, `GET /workspaces/:id/pointers`, `DELETE /pointers`를 위 내부 경로로 프록시하고, 프록시에서 idempotency를 처리한다.
