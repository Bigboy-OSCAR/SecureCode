# Video Summary: HTML/CSS/JS를 활용한 AI 기반 PPT 제작 및 활용 가이드

## 1. Overview (개요)
- **핵심 개념**: 기존의 파워포인트(PPT) 소프트웨어(M365 Copilot, Gemini 등)를 사용하는 고정관념에서 벗어나, AI를 활용해 **HTML/CSS/JavaScript 코딩으로 슬라이드 형태의 문서를 제작**하는 방법과 장단점을 소개함.
- **주요 타겟**: 차별화된 발표 자료를 원하는 발표자, 영상 제작자(유튜버), 개발자 등.

---

## 2. Advantages of HTML-based Slides (HTML PPT의 장점)
- **높은 자유도 및 표현력**: 
  - 정형화된 PPT 애니메이션을 뛰어넘는 고자유도 애니메이션 구현 가능.
  - 인풋(Input)에 실시간으로 반응하는 인터랙티브(Interactive) 요소 삽입 가능.
  - 브라우저 전체 화면(F11) 기능을 활용하므로 실제 PPT와 구동 방식에서 차이가 없음.
- **다양한 라이브러리 연동**:
  - `Chart.js` 같은 라이브러리를 명시하여 라인 차트, 파이 차트 등 사장님이 좋아할 만한 고품질 차트와 표를 데이터 기반으로 쉽게 생성 및 수정 가능.
  - `Three.js`를 연동하여 3D 모델 렌더링, 시뮬레이션, 3D 공간 데이터 분포도(예: Lab 색상 분포) 시각화 가능.
- **구조적 유연성**:
  - 자바스크립트를 활용한 서브 페이지 구현이 쉬워, 기존 PPT의 일직선(Linear) 진행 구조에서 탈피 가능.
- **배포 및 관리 편의성**:
  - 코드로 이루어진 문서이므로 GitHub에 업로드하여 백업하고, GitHub Pages를 통해 URL로 즉시 배포 가능 (PPT 파일을 들고 다닐 필요 없음).
  - 반응형 디자인(Responsive Design) 적용 시 모바일 레이아웃 대응 가능.
  - 브라우저 개발자 도구의 'Full size screenshot' 기능을 통해 이미지 파일로도 쉽게 변환 가능.
  - HTML 코드를 웹사이트/블로그에 그대로 삽입 가능하여, 사용자의 페이지 체류 시간(Dwell Time)을 늘리고 SEO(검색 순위 1위 달성)에 기여함.

## 3. Practical Workflow with AI (AI 활용 제작 방법 및 프롬프트 팁)
- **기본 생성**: LLM(Gemini, ChatGPT, Claude 등)에게 *"HTML, CSS로 PPT 스타일의 슬라이드를 만들어줘"*라고 프롬프트를 입력하면, 이미지가 없을 경우 CSS Art로 직접 그려줄 정도로 퀄리티 높게 뽑아줌.
- **LLM 모델 추천**: 디자인 레이아웃의 에러(찐빠)가 가장 적은 **Claude**를 추천함.
- **AI Agent 활용**: 
  - 단일 파일에 모든 레이아웃을 작성하면 수정 시 토큰 소모가 크고 시간이 오래 걸리므로, **Cursor** 등의 AI 에인전트를 활용해 여러 파일로 컴포넌트를 분리(나누기)하도록 지시하는 것이 좋음.
  - AI 에이전트를 쓰면 가이드 문서를 MD(Markdown) 파일로 저장해 두고 지속해서 재사용할 수 있어 프롬프트를 매번 수정할 필요가 없음.
  - MCP(Model Context Protocol)나 추가 스킬을 장착하여 이미지 생성 기능을 더하거나, 다른 유저들이 만든 '프론트엔드 PPT 제작 스킬' 등을 설치해 디자인 퀄리티를 보완할 수 있음.

---

## 4. Limitations & Challenges (단점 및 주의사항)
- **AI의 폰트 및 디자인 인지 한계**:
  - AI가 한글 폰트를 잘 모르기 때문에, 사용자가 프롬프트에 직접 적용할 폰트를 명시해야 함.
  - AI가 기본적으로 글씨 크기를 작고 오밀조밀하게 만들어주는 경향이 있어 발표용/영상용으로는 가독성이 떨어짐 (텍스트 양을 줄이고 크기를 키우도록 수동 조정 필요).
  - 디폴트 디자인으로 쓸데없이 다크 모드(Dark Mode)를 자주 적용해 줌.
- **정보 검증 필요**: 다이어그램이나 기술적 시뮬레이션 과정을 시각적으로 잘 그려주지만, 출력된 정보의 정확성에 대해서는 사용자의 직접적인 판단 및 검증이 필요함.
