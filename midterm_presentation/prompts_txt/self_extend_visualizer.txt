[중요 출력 조건]
이 프롬프트는 한글로 작성되어 있지만, 이 프롬프트를 통해 생성되는 최종 결과물은 반드시 영어여야 합니다.
React 앱의 모든 UI 텍스트, 버튼, 라벨, 패널 제목, 그래프 캡션, 도움말 문구, 코드 주석, 예시 문장, 설명 문단은 영어로 작성해 주세요.

[목적]
LLM의 제한된 컨텍스트 윈도우(Context Window)를 재학습 없이 추론 시점의 attention/position 처리 방식으로 확장하는 'Self-Extend'의 동작 과정을 이해할 수 있도록 돕는 웹 기반 인터랙티브 애니메이션 도구를 제작해 주세요. (React, Tailwind CSS, Framer Motion 사용)

이 시각화는 실험 결과, 성능 평가, 한계점, 성공/실패 사례를 보여주는 도구가 아닙니다. 오직 Self-Extend가 내부적으로 어떤 순서로 token 위치와 attention 범위를 재배치하는지 설명하는 데 집중해 주세요.

[설명해야 할 동작 과정]
1. Base Context Window:
   - 모델이 기본적으로 학습된 context length 안에서 token position을 해석하는 모습을 보여주세요.
   - token stream이 순서대로 context slot에 들어가고, 각 token이 position id를 배정받는 과정을 애니메이션으로 표현해 주세요.
   - 기본 attention map에서는 각 token이 기존 position grid 위에 배치되는 모습을 보여주세요.

2. Context Boundary Detection:
   - 입력 token 수가 base context window 경계에 가까워지는 과정을 보여주세요.
   - 경계선은 `Trained Context Boundary`라고 표시하고, 이 선을 기준으로 기본 position mapping이 더 이상 단순 확장되지 않는다는 구조만 설명해 주세요.

3. Self-Extend Activation:
   - `Enable Self-Extend` 버튼을 누르면 새로운 mapping layer가 추가되는 것처럼 보여주세요.
   - 기존 token sequence가 `Local Neighbor Window`와 `Grouped Position Layer`라는 두 영역으로 재배치되도록 시각화해 주세요.
   - 이때 context bar가 단순히 길어지는 것이 아니라, position/address mapping 방식이 바뀌는 것처럼 표현해야 합니다.

4. Local Neighbor Window:
   - 현재 처리 위치와 가까운 token들은 high-resolution local window 안에 남습니다.
   - 가까운 token은 촘촘한 grid, 선명한 색상, 짧은 attention link로 표현해 주세요.
   - 이 영역은 세밀한 순서 정보와 근거리 token 관계를 유지하는 구간으로 설명합니다.

5. Grouped Position Layer:
   - 먼 token들은 group factor에 따라 여러 token이 하나의 coarse group으로 묶입니다.
   - `G=2`, `G=4` segmented control을 제공하고, group factor가 커질수록 더 많은 token이 하나의 grouped lane에 압축 배치되는 모습을 보여주세요.
   - 각 group에는 원래 token range와 새 grouped position id가 함께 표시되어야 합니다.

6. Position Remapping:
   - token의 원래 위치가 `Original Position`에서 `Remapped Position`으로 변환되는 과정을 화살표와 transformation table로 보여주세요.
   - 예시 테이블 컬럼은 영어로 `Token`, `Original Pos`, `Group`, `Local/Grouped`, `Remapped Pos`를 사용합니다.
   - local token은 거의 그대로 유지되고, distant token은 grouped position으로 변환되는 차이를 명확히 보여주세요.

7. Attention Flow:
   - attention map을 두 층으로 나누어 보여주세요.
   - 첫 번째 층은 `Local Attention`으로, 가까운 token 사이의 세밀한 연결을 표시합니다.
   - 두 번째 층은 `Grouped Attention`으로, 먼 token group 사이의 coarse connection을 표시합니다.
   - 두 층이 합쳐져 긴 sequence를 하나의 확장된 view로 다루는 과정을 보여주세요.

[핵심 시각화 요소]
1. Context Slot View:
   - 8~12개의 slot으로 단순화된 base context window를 보여주세요.
   - token이 slot에 들어갈 때마다 position id label이 붙도록 합니다.
   - 경계에 가까워질수록 `Boundary` indicator가 활성화됩니다.

2. Layered Mapping View:
   - base context 위 또는 아래에 `Self-Extend Mapping Layer`가 펼쳐지는 애니메이션을 구현해 주세요.
   - local lane과 grouped lane이 분리되어 보이도록 색상과 높이를 다르게 사용합니다.
   - token group이 접히고 펼쳐지는 accordion-like animation을 넣어 주세요.

3. Group Factor Control:
   - `Off`, `G=2`, `G=4` segmented control을 제공합니다.
   - `Off`에서는 모든 token이 base position grid에만 배치됩니다.
   - `G=2`에서는 먼 token이 2-token group으로 묶입니다.
   - `G=4`에서는 먼 token이 4-token group으로 묶입니다.
   - control 변경 시 token grouping과 remapped position table이 즉시 업데이트됩니다.

4. Step Timeline:
   - 오른쪽에 단계별 timeline panel을 배치하고 다음 단계가 순서대로 활성화되게 해주세요.
     1. `Tokens enter the base window`
     2. `Boundary is detected`
     3. `Self-Extend layer is enabled`
     4. `Nearby tokens stay local`
     5. `Distant tokens are grouped`
     6. `Positions are remapped`
     7. `Attention reads local and grouped layers`
   - 각 단계가 활성화될 때 중앙 시각화의 관련 요소가 하이라이트되어야 합니다.

5. Metaphor View:
   - 기본 상태는 좁은 렌즈로 가까운 token만 보는 모습으로 표현해 주세요.
   - Self-Extend 상태는 같은 화면에 fine local lens와 coarse panorama lens가 동시에 존재하는 모습으로 표현해 주세요.
   - 이 메타포는 내부 동작 설명용이며 성능 결과나 한계점 설명으로 확장하지 마세요.

[디자인 요구사항]
- 전체 결과물은 영어 UI로 작성합니다.
- Self-Extend의 동작 과정만 설명하고, 실험 결과, 벤치마크 수치, 실패 사례, 한계점, 적용 판단은 포함하지 마세요.
- 기술 시각화 도구처럼 보이게 하고, token movement, grouping, remapping, attention layer가 명확하게 보이는 layout을 우선합니다.
- 색상은 base context, boundary, local window, grouped layer, remapped position을 구분하는 용도로 사용합니다.
- 마지막 요약 패널에는 영어로 다음 메시지를 담아 주세요: Self-Extend remaps long token sequences by keeping nearby tokens local and grouping distant tokens into coarser positions.
